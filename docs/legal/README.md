## 서비스 개시 전 행정 절차 (대한민국)

1. **사업자등록** (홈택스) — 필수
2. **통신판매업 신고** (정부24) — 온라인 유료 판매 시 필수.
   단, 직전연도 통신판매 거래 횟수 50회 미만이거나 부가가치세법상 간이과세자는 면제.
   면제 대상이라도 결제대행사(PG) 심사에서 요구하는 경우가 많습니다.
3. **결제대행사 계약** — 국내: 토스페이먼츠 / 포트원(구 아임포트) / NHN KCP,
   해외 매출 포함: Stripe. 정기결제(구독)를 쓰려면 빌링키 발급 계약이 필요합니다.
4. **개인정보처리방침 게시** 및 개인정보 보호책임자 지정
5. **사업자 정보 표시** — 상호·대표자·주소·전화·사업자등록번호·통신판매업신고번호를
   웹사이트에 표시 (전자상거래법)
