# 📓 매매일지 (Trading Journal)

차트 이미지 + 코멘트로 매매를 복기하고, **일별 / 주별 / 월간**으로 성과를 관리하는 단일 파일 웹앱입니다.
설치·회원가입·서버 없이 `index.html` 하나만 열면 바로 동작합니다.

---

## ✨ 기능

| 구분 | 내용 |
|---|---|
| 🖼 **차트 이미지** | `Ctrl+V` 붙여넣기 · 드래그&드롭 · 파일 선택 (한 일지에 여러 장), 클릭 시 확대(라이트박스) |
| ✍️ **코멘트** | 진입/청산 근거, 잘한 점, 개선할 점을 자유롭게 기록 + 태그 + ★평점(1~5) |
| 📅 **일별** | 하루 단위 일지 목록, 그날의 손익·승률·평균손익, 주간 스트립으로 요일 이동 |
| 🗓 **주별** | 7일 손익 한눈에, 주간 손익·승률·수익 난 날·손익비(PF) |
| 📆 **월간** | 손익 히트맵 캘린더(수익=초록/손실=빨강), 주차별·일자별 손익 막대 |
| 📈 **통계** | 누적 손익 곡선, 월별·요일별·태그별·종목별 성과, 최고/최악 거래 |
| 🔍 **검색** | 종목·태그·코멘트 전문 검색 (모든 뷰에 즉시 반영) |
| 🧮 **자동 계산** | 진입가·청산가·수량·수수료 → 손익금액/수익률 자동 계산 (롱/숏 반영, 직접 입력 시 수동 우선) |
| 💾 **백업** | JSON 내보내기/불러오기(이미지 포함), CSV 내보내기(엑셀용) |
| 🌗 기타 | 다크/라이트 테마, 모바일 대응, 일지 복제, 단축키 |

## 🚀 사용 방법

### 0. 바로 접속 (Claude 아티팩트 URL)
https://claude.ai/code/artifact/e8692531-469b-4346-8727-0e98d23d2438
계정 소유자에게만 보이는 비공개 페이지이며, 페이지의 공유 메뉴에서 링크를 공개할 수 있습니다.

### 1. 그냥 열기 (가장 간단)
`trading-journal/index.html` 파일을 더블클릭 → 브라우저에서 바로 실행됩니다.

### 2. GitHub Pages로 웹사이트 공개
**Settings → Pages** 에서

- **Source: Deploy from a branch** / Branch: `main` / Folder: `/ (root)` 로 설정하면
  → `https://<사용자명>.github.io/posco-ppi-agent/trading-journal/` 로 접속
- 또는 **Source: GitHub Actions** 로 설정하면 포함된 워크플로(`.github/workflows/pages.yml`)가
  `trading-journal/` 폴더만 배포 → `https://<사용자명>.github.io/posco-ppi-agent/` 로 접속

### 3. 로컬 서버로 실행
```bash
cd trading-journal
python -m http.server 8000
# http://localhost:8000
```

| 키 | 동작 |
|---|---|
| `N` | 새 일지 작성 |
| `←` `→` | 이전/다음 (일·주·월 단위로 이동) |

| `Esc` | 창 닫기 |

## 💾 데이터 저장 방식 (꼭 읽어주세요)

- 모든 일지와 이미지는 **브라우저의 IndexedDB(내 PC)** 에만 저장됩니다. 서버로 전송되지 않습니다.
- 따라서 **브라우저 데이터를 지우거나, 다른 기기·다른 브라우저로 가면 기록이 보이지 않습니다.**
- 기기를 옮기거나 백업하려면 `⋯ → 백업 내보내기(JSON)` 로 파일을 저장한 뒤,
  다른 기기에서 `⋯ → 백업 불러오기` 로 복원하세요. **주기적인 백업을 권장합니다.**
- 시크릿/사생활 보호 모드에서는 저장이 제한될 수 있습니다.
- 접속 주소가 다르면(아티팩트 URL / GitHub Pages / 로컬 파일) 저장소도 각각 분리됩니다.
  주소를 옮길 때는 JSON 백업으로 이동하세요.
- 업로드한 이미지는 가로·세로 최대 2000px, 품질 92%의 JPEG로 자동 압축되어 저장 용량을 아낍니다.
  (원본 그대로 보관하려면 별도로 파일을 보관하세요.)

## 🛠 기술 메모

- 의존성 0개 (프레임워크·CDN·빌드 없음), 단일 HTML 파일 `index.html`
- 저장소: IndexedDB (`trading-journal` DB / `entries`, `images` 스토어)
- 이미지: `<canvas>` 리사이즈 → Blob 저장 + 썸네일(dataURL) 캐시
- 차트: 인라인 SVG 직접 렌더링
